Структура застосунку

За основу беремо ДЗ на React з минулої лекції та розбиваємо його на компоненти, сторінки й додаємо роутер. Застосунок тепер матиме такий вигляд:

Роутер: за допомогою роутера ділимо застосунок на 3 сторінки

home: /

heroes: /heroes
hero: /heroes/id (id: номер вибраного персонажа)
about: about
Панель навігації зліва, завжди на екрані

Усі компоненти стилізуємо за допомогою MUI (посилання в описі). В ідеалі вивчити всі наявні компоненти й замінити всі стандартні HTML-теги на них.

Список персонажів з Rick and Morty API відобразити у вигляді таблиці (https://mui.com/x/react-data-grid/), у ній будуть такі колонки: id, name, status

При натисканні на рядок із персонажем збоку з’являється панель із картинкою та описом, як у Telegram (панель справа), за допомогою роутера за маршрутом /heroes/id (id: вибраний персонаж)

приклад обробника:

onRowClick={handleRowClick} // Обробник кліку по рядку

Зробити перемикач тем, День/Ніч. При перемиканні колір усіх елементів змінюється на темний (для стилізації MUI-компонентів необхідно перезаписати їхні рідні стилі)

Приклад-підказка: sx={{ '& .MuiDataGrid-row': { backgroundColor: 'lightblue' }, // Колір фону для всіх рядків '& .MuiDataGrid-row:hover': { backgroundColor: 'lightgreen' }, // Колір при наведенні }}
